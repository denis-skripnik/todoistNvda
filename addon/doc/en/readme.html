Todoist for NVDA

Todoist for NVDA adds a global Todoist task manager to NVDA.

Features

  • Open the main window from NVDA Tools or with NVDA+Windows+T
  • Browse Todoist projects and active tasks
  • Search within the current task list
  • Add, complete, reopen, edit, and delete tasks
  • Create projects from the main window
  • Open nested subtasks and add new subtasks
  • Manage labels with checkboxes and create new labels from the task editor
  • View completed tasks and reopen them
  • Receive a due-time reminder dialog with Complete and OK
  • Receive a daily summary of today's incomplete tasks at a configured time

Task tree navigation

Tasks and subtasks use a native tree with accessible levels and expanded/collapsed states. Press Right Arrow to expand a task, Down Arrow to visit its children, and Left Arrow to collapse it (or return to its parent). Tab reaches the action buttons for the selected task at any depth. Escape clears the selection and enables Add. Use the Subtasks button to open a branch and add a subtask there. Refresh preserves surviving selections and expanded branches. Matching tasks remain visible when search or label filters exclude their parents.

Interface language

The interface follows the NVDA interface language. Russian (including regional variants) uses Russian; English and other languages use English. Restart NVDA after changing its language. Menus, settings, dialogs, months and notifications are localized. Task, project and label names and raw external errors are unchanged. Standard OK/Cancel buttons follow NVDA/wx localization.

Settings

Open NVDA Settings and configure the Todoist API key and the daily incomplete-task summary time in HH:MM format.

Notes

  • Due-time reminders are shown for tasks that have a specific time today.
  • Daily summaries include active tasks whose due date is today.
  • New labels are created without spaces and with a maximum length of 40 characters.
